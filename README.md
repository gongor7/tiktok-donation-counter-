# 🎵 TikTok Live Donation Counter Overlay

Un sistema interactivo de contador de donaciones en tiempo real para transmissiónes de TikTok Live con Overlay transparente para OBS Studio y Dashboard de control con simulador.

## 🚀 Características
- **Conexión en vivo**: Conexión con transmisiones de TikTok Live vía @username
- **Overlay Animado para OBS**: Barra de progreso dinámica de meta + Notificaciones animadas de regalos (Pop-up)
- **Panel de Control (Dashboard)**: Ajuste de meta en tiempo real, reinicio a 0 y simulador de regalos
- **Simulador Integrado**: Permite probar animaciones y suma de monedas sin estar en vivo

## 🛠️ Instalación y Uso
`ash
npm install
node server.js
`

- **Overlay para OBS**: http://localhost:3000/overlay.html
